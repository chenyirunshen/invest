# 凡哥的投资指南

> 凡哥的投资学习笔记

移动端优先的可视化投资看板。标的：**纳斯达克 / 黄金 / 债券**，方法：**何刚投资方法论**（自上而下：政策面 → 宏观面 → 基本面）。

纯静态文件，零依赖，零构建。改完 `data/*.js` 推到 GitHub 就生效，手机打开链接随时看。

---

## 一、目录结构

```
投资指南/
├── index.html          页面骨架（6 个 Tab：今日 / 诊断 / 标的 / 方法论 / 迭代 / 工具）
├── assets/
│   ├── style.css       样式（支持深浅色切换）
│   └── app.js          渲染逻辑（一般不用改）
├── data/
│   ├── market.js       ★ 每日维护：宏观 8 指标 + 三标的信号灯 + 每日观察
│   ├── assets.js       ★ 每周维护：三标的深度分析 + 配置方案 + 常见坑
│   ├── framework.js    方法论（很少改，除非框架本身升级）
│   ├── journal.js      ★ 每次认知升级：思想迭代日志 + 假设台账
│   └── portfolio.js    ★ 持仓诊断：分析维度 + 诊断归档 + 学习路径
└── README.md
```

**日常只需要动打 ★ 的三个文件。**

> ⚠️ **改完看不见变化？** GitHub Pages 有 CDN 缓存。改了 css / js 后，把 `index.html` 里引用上的 `?v=3` 全部 +1（现在是 3），再推送——这是最可靠的强制刷新。手机上也可以直接清浏览器缓存 / 用无痕模式打开。

## 二、部署到 GitHub

### 方式 A：独立新仓库（推荐，链接干净）

```bash
cd 投资指南
git init
git add .
git commit -m "v0.1 建站：纳斯达克/黄金/债券 定投分析"
git branch -M main
git remote add origin https://github.com/chenyirunshen/invest.git
git push -u origin main
```

然后进仓库 → **Settings → Pages → Source 选 `main` / 根目录** → 保存。
一两分钟后访问：**https://chenyirunshen.github.io/invest/**

### 方式 B：放进现有仓库当栏目

直接把 `投资指南/` 整个目录拷进现有仓库（比如「刘继凡工作台」），在首页加个入口链接指向 `投资指南/index.html` 即可。
Pages 已开启的话，路径形如 `https://xxx.github.io/仓库名/投资指南/`。
（中文路径会被 URL 编码，能用但不好看，建议目录名改成 `invest`。）

### 手机收藏

用手机浏览器打开上面的地址 → 分享 → 「添加到主屏幕」。图标 + 全屏，和 App 一样。

## 三、维护节奏

| 频率 | 做什么 | 改哪个文件 |
|---|---|---|
| **每天 2 分钟** | 更新宏观 8 个指标；在 `days` 最前面加一条「今日观察」（利好 / 利空 / 我的判断 / 下一步） | `data/market.js` |
| **每周日 10 分钟** | 更新三标的的信号灯颜色（green/yellow/red/blue）和 verdict 一句话 | `data/market.js` 的 `assets` |
| **有大事时** | 更新标的的深度分析（扇面三层、关键读数、风险） | `data/assets.js` |
| **每次认知升级** | 版本号 +1，写一条日志；有新判断就往 `hypotheses` 加一条 | `data/journal.js` |
| **每季度** | 回看假设台账，把到期的标成「成立 / 证伪」，写清学到了什么 | `data/journal.js` |
| **每次持仓变动** | 做一次诊断，把结论写进 `reviews` 归档 | `data/portfolio.js` |

### 每日观察怎么写（模板）

```js
{
  date: "2026-10-08",
  title: "一句话说清今天最重要的事",
  good: ["利好1（带数字）", "利好2"],
  bad:  ["利空1（带数字）", "利空2"],
  takeaway: "今天的判断：…… 为什么这么看",
  action: ["今天唯一要动手的一件事"]
}
```

**规则：利好利空必须带数字。** "美股上涨"不算观察，"纳指 +0.45% 创收盘新高"才算。

## 四、持仓诊断怎么用

### 用法零：上传截图（存在手机本地）

「诊断」页第一个卡片就是上传窗口：填一句备注 → 点「＋ 选图 / 拍照」→ 选一张或多张。

- 图片会自动压缩到长边 1000px（JPEG 0.72），存进浏览器 **IndexedDB**，**不上传任何服务器**
- 点缩略图看大图，右上角 ✕ 删除
- 填了持仓金额后，「复制一份给小爪的分析请求」会把持仓数据 + 六个维度打包成一段文字，复制走发给小爪，图另发

⚠️ 数据存在浏览器本地，**换设备、清缓存、用无痕模式都会丢**。重要的持仓记录建议另外截图存一份。

### 用法零·二：AI 读图（配一次，之后全自动）

站点是纯静态的，本身读不出截图里的数字。接一个视觉大模型就能自动识别：

1. 「诊断」页 → **⚙️ 接入视觉大模型** → 选服务商、填 API Key → 点「保存并测试连接」
2. 上传截图后会出现紫色的 **🤖 AI 读图 · 自动识别并分析** 按钮
3. 点一下：模型识别截图里的每个条目 → 自动归类（债券/纳指/黄金/现金/其他）→ 自动填入金额 → 跑规则引擎 → 再让模型写一段诊断意见

支持三家，都是 OpenAI 兼容格式：

| 服务商 | Key 申请 | 默认模型 | 备注 |
|---|---|---|---|
| 智谱 | open.bigmodel.cn | `glm-4v-flash` | 有免费额度，中文界面识别最好 |
| 通义千问 | bailian.console.aliyun.com | `qwen-vl-max-latest` | 阿里百炼 |
| OpenAI | platform.openai.com | `gpt-4o-mini` | 需外币卡 |
| 自定义 | — | 自填 | 填自己的 OpenAI 兼容代理地址 |

- **Key 只存在你手机浏览器的 localStorage，不上传服务器，也不会进 GitHub 仓库**（它不在任何文件里）。
- 若报跨域（CORS）错误 = 该服务商不允许浏览器直连，换上面三家之一或填代理地址。
- 识别可能有误差，**填完务必核对金额**再往下走。

### 用法一：手机自测（10 秒）

进「诊断」页，填上各标的市值 + 月生活支出，点「诊断我的持仓」，立刻出四样东西：

1. **结构** — 每项占比 vs 目标配置，粗条是实际、细刻度是目标，一眼看出超配低配
2. **六项体检** — 核心/卫星结构、纳指集中度、黄金对冲层、制度摩擦、债券久期、现金垫，逐项给「达标 / 注意 / 需调整」
3. **压力测试** — 三种情景下你的组合会亏多少（不是预测，是体检：跌多少你会睡不着，那就是仓位上限）
4. **再平衡建议** — 精确到金额：哪项该加多少、该减多少

**再平衡的执行原则：用新增资金补低配的那一项，而不是卖出超配的那一项。** 少一次交易，少一次费用和情绪波动。每季度只做一次。

### 用法二：发截图给小爪（深度诊断）

把券商 / 基金 App 的持仓截图发给小爪，会按 `data/portfolio.js` 里的**六个维度**出一份诊断，归档到「诊断」页，并同步更新「迭代」页的假设台账。

截图里最好能看到：① 各标的市值与占比 ② 持仓成本与浮盈浮亏 ③ 场内 ETF 的溢价率 ④ 定投计划与已投期数。看不到也没关系，能看多少算多少。

**六个维度**（合格线写在站点里）：

| 维度 | 合格线 |
|---|---|
| ① 核心/卫星结构 | 核心（债券+现金）45%–60% |
| ② 纳指集中度 | ≤ 35%（超过就是押注不是配置） |
| ③ 黄金对冲层 | 5%–15% |
| ④ 制度摩擦 | 场内 ETF 溢价 < 5% 才能买 |
| ⑤ 债券久期 | 国内中短久期，不碰长久期美债 QDII |
| ⑥ 现金垫 | ≥ 6 个月生活费 |

## 五、这个站的设计原则

1. **不预测，只执行。** 定投的全部价值在于放弃择时。看板的作用是让你按纪律扣款，不是让你多操作。
2. **先过滤制度摩擦，再谈市场判断。** 境内买纳指最大的敌人不是波动，是 QDII 限购和 ETF 溢价。
3. **框架是骨架，数据是血肉。** 方法论背下来，输入参数每天换。缺一个都是僵尸。
4. **写下判断 + 证伪条件 + 检验日期。** 到期回来看。被证伪的判断才是真正学到的东西。
